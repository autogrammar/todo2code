- `new-ticket.sh` accepted `--users` but did not consistently materialize the
  documented structure.
- Documentation claimed automatic `user-*` generation despite the rule that an
  agent must not write human-owned content.

  generated analysis namespace used by todo2code.

  claims without explicit role metadata.

  replacement failed.
